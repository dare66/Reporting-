# ADR 0007 — "Signal" design system

**Status:** accepted

Dark Intelligence is the primary environment, with a designed (not inverted) light theme. Data colours come from a categorical palette validated for colour-vision deficiency and contrast on both surfaces; a single amber brand accent is reserved for UI chrome and never encodes data; AI-generated content carries a consistent violet identity; status colours ship with glyph + label. Every chart has a table view, partial periods are drawn as dashed segments, and motion respects `prefers-reduced-motion`.
